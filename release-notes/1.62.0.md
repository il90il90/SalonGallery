## What's new

**Add is simpler**
Google Photos now lives inside the "Photos & video" menu, so the home screen has one clear Add button instead of two.

**"Mix" layout**
The slideshow's "Random" layout is now called "Mix" (it mixes the layouts) and sits first in the list.

**Upload progress up top**
"Sending …" now shows right under the photo at the top, where you can see it.
